# Practice Projects

A collection of small hands-on projects built while learning full-stack web development — spanning Node/Express, Django, React, and plain HTML/CSS/JS. Each folder is a self-contained exercise focused on a specific concept or stack.

## Contents

### FSWD — Full-Stack Web Dev Practice
- **`B_END/MAJOR`** — Express + MongoDB/Mongoose CRUD app rendered with EJS templates.
- **`B_END/MINOR`** — Smaller Express app with a dedicated `routes/users.js`, practicing route separation.
- **`F_END/MAJOR`** — Static multi-page event website (home, about, gallery, pricing, registration, testimonials, timeline) built with plain HTML/CSS.
- **`F_END/MINI`** — Minimal HTML/CSS practice page.

### Gallery
Django backend (`Gallery_Backend-main`) for an image gallery app, with a custom management command to sync media with Cloudinary.

### IDPST
Two-part app: a Django backend (`B_End/b_pro`) paired with a React frontend (`F_End/idpst`).

### pickup
Node/Express practice app.

### todo
A React (Create React App) to-do list app.

## Tech Stack Covered

| Area | Technologies |
|---|---|
| Backend | Node.js, Express, Django |
| Database | MongoDB (Mongoose), SQLite |
| Frontend | React, EJS, HTML/CSS/JS |
| Media | Cloudinary |

## Purpose

This repo is a learning log, not a production project — each subfolder can be run independently. See each folder for its own setup (most Node apps need `npm install`; Django apps need `pip install -r requirements.txt` and `python manage.py migrate`).
